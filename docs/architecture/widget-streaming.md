## Phase 1 transport and controls

- Set `WIDGET_AI_STREAMING_ENABLED=true` on the API and worker in a test environment. The default is off. No database migration is required. Refresh the versioned embed snippet if the storefront has cached an older script.
- The gateway consumes OpenAI-compatible chat completion SSE, accounts for usage when the provider reports it, and enforces a wall clock timeout and bounded response size. The worker writes batched deltas to an organization, conversation, execution, and attempt scoped Redis stream. Entries expire after 120 seconds. Redis is a replay buffer. PostgreSQL remains authoritative for queue state and completed messages.
- The public endpoint is `GET /api/v1/widget/conversations/{conversation_id}/reply-stream`. It uses the existing bearer token and storefront origin rules. Reconnection uses `after` with the last event sequence. The browser discards partial content on an attempt change, failure, or handoff and reconciles the committed message through history.
- Grounded automatic replies with citations can stream when there is no private integration context. If prior generated or staff replies are present, standalone questions stream using the current question and authorized sources. Follow-ups that depend on those prior replies use the full context and completed-response path.
- Configure the proxy to avoid SSE buffering. Use a staged storefront to confirm incremental rendering, reconnect, worker restart, revocation, and handoff. Measure browser submit-to-acknowledgment, first visible delta, and final committed reply. The gateway logs first provider delta and generation duration without message content.
- For rollback, turn the flag off on the API and worker. Existing embeds fall back to history polling. Redis stream keys age out automatically.
- Release gaps include real-provider and storefront timing, browser/mobile accessibility validation, and staging verification of proxy behavior and load. Text already displayed provisionally cannot be recalled after a later authorization or ownership change.
